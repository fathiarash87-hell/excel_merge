# ادغام و گزارش‌گیری فایل‌های اکسل

یک اسکریپت پایتون که چند فایل اکسل هم‌ساختار را در یک فایل ادغام می‌کند، جمع و میانگین هر فایل را حساب می‌کند و یک گزارش اکسل فرمت‌شده همراه با نمودار می‌سازد.

## امکانات

- خواندن خودکار همه‌ی فایل‌های `.xlsx` داخل پوشه‌ی `data`
- ادغام آن‌ها در یک جدول و افزودن ستون `Source` (اسم فایل مبدا)
- محاسبه‌ی جمع، میانگین، کمینه و بیشینه‌ی `salary` برای هر فایل
- ساخت `report.xlsx` با دو شیت:
  - **Merged**: همه‌ی ردیف‌ها
  - **Summary**: خلاصه‌ی هر فایل
- فرمت‌بندی هدر، تنظیم عرض ستون‌ها، ثابت‌کردن ردیف اول و افزودن نمودار

## نیازمندی‌ها

- Python 3.8 یا بالاتر
- کتابخانه‌ها:

```
pip install pandas openpyxl
```

## ساختار پروژه

```
excel_merge/
├── data/          فایل‌های اکسل ورودی (مثلاً jan.xlsx, feb.xlsx, mar.xlsx)
├── merge.py       اسکریپت اصلی
├── report.xlsx    خروجی (بعد از اجرا ساخته می‌شود)
└── README.md
```

## نحوه اجرا

1. فایل‌های اکسل هم‌ساختار را داخل پوشه‌ی `data` بگذارید (همه باید ستون `salary` داشته باشند).
2. اسکریپت را اجرا کنید:

```
python merge.py
```

3. فایل `report.xlsx` کنار اسکریپت ساخته می‌شود.

## نکته

اگر هنگام اجرا خطای `PermissionError` دیدید، فایل `report.xlsx` را در اکسل ببندید و دوباره اجرا کنید.
